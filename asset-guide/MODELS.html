실제 연결된 AI 모델과 GPU 사양

시작 안내 · 아키텍처 · 배포 그림

새 후보는 Qwen3-ASR 0.6B·1.7B, Kokoro-82M 및 최신 MiniCPM 계열 검토에 정리했습니다. Qwen 1.7B·Supertonic 3는 공유 데모에 연동했고, Qwen3-ASR 0.6B·1.7B도 GPU2에 연동했습니다. Kokoro를 제거하고 Ppaso-TTS 한국어 ONNX CPU 경로로 교체했습니다. CosyVoice 3는 현재 앱 선택지에 추가하지 않았습니다. Kokoro는 별도 한국어 실행 진단을 수행했으며, Qwen3-ASR의 동일 입력 비교는 STT 비교에 정리합니다.

Supertonic 3·Qwen3-TTS 1.7B·CosyVoice 3는 별도 8문장 실행 비교를 완료했습니다. 이후 Qwen 1.7B·Supertonic을 앱 선택지로 추가했습니다. Polly 기본값은 유지합니다.

기본 단계형 요청: Whisper large-v3-turbo → Qwen3.5-4B NF4 → 서버 검증·실행 → Polly Seoyeon.

이 문서의 “기본”은 카탈로그·UI·서버의 기본 선택 설정입니다. 현재 GPU에 무엇이 올라와 있는지 실시간 조회한 목록이 아닙니다. 아래 모델 크기는 저장소 카탈로그의 기록이며 제품명에 붙은 숫자와 전체 파라미터 수를 구분합니다.

어떤 모델이 함께 상주하나요?

GPU 1의 Core 워커는 판단 모델 1개를 적재하고 Nemotron ASR은 필요할 때 적재합니다. Whisper·Qwen TTS 0.6B·Qwen TTS 1.7B·MiniCPM은 별도 GPU 워커이며, 활성화되어 로딩에 성공하면 같은 L40S의 VRAM을 함께 점유합니다. 판단 모델을 Qwen에서 Gemma로 바꿔도 큰 판단 모델의 공간이 부족하면 사용하지 않는 Nemotron을 해제합니다. 다른 TTS·MiniCPM 워커는 유지합니다.

GPU 2는 추가 음성 모델 중 하나만 실행합니다. 모델을 바꾸면 이전 프로세스를 종료하고 새 프로세스를 실행합니다.

기본 요청에서 사용하는 것은 Whisper와 선택한 판단 모델이며, 음성 응답은 기본적으로 외부 Polly입니다. 이때 사용하지 않는 활성 워커도 GPU 메모리에 남아 있을 수 있습니다. 동시 상주와 한 요청의 호출 경로는 별개입니다. 워커별 표와 그림을 참고하세요.

Supertonic 3는 GPU 1 호스트의 CPU에서 별도 실행하며 GPU VRAM을 쓰지 않습니다. 모델 ID는 Supertone/supertonic-3, 목소리는 F1, 샘플레이트는 44.1kHz입니다.

Whisper는 Transformers의 AutoModelForSpeechSeq2Seq로 직접 로드합니다. OpenAI 관리형 음성 API나 faster-whisper를 호출하는 구성이 아닙니다. Nemotron의 제품명에 streaming이 들어가지만 이 앱의 해당 경로는 발화 단위 업로드로 처리합니다.

Qwen/Qwen3.5-4B의 BF16와 NF4는 동일 체크포인트의 두 로딩 설정입니다. NF4는 선택한 선형 계층에 적용하며 double quantization과 BF16 연산을 사용합니다. STT·TTS까지 모두 4bit로 바뀌는 것은 아닙니다.

워커 시작 상태와 앱 기본 선택은 다릅니다. runtime/model_server.py는 시작할 때 Qwen3.5-4B BF16을 먼저 로드합니다. 카탈로그 기본값 qwen35-4b-nf4로 요청하면 NF4로 교체합니다. 따라서 재시작 직후 GPU 상태를 앱 기본 구성과 동일하다고 단정하면 안 됩니다.

MiMo는 별도 XiaomiMiMo/MiMo-Audio-Tokenizer도 사용합니다. Moshi는 저장소에 함께 있는 Mimi 코덱 체크포인트를 로드합니다. runtime/speech_manager.py는 모델을 바꿀 때 기존 프로세스를 종료하고 새 프로세스를 실행하므로 이 네 모델이 동시에 상주하지 않습니다.

Nemotron과 Qwen TTS의 로더에는 명시적인 revision 인자가 없습니다. 설치·캐시 시점에 따라 받아오는 버전이 달라질 수 있습니다.

  • 앱 기본값·모델 크기: model-catalog.json, public/catalog.js.
  • STT: runtime/whisper_server.py, runtime/model_server.py.
  • 판단 모델·NF4·Qwen TTS: runtime/model_server.py.
  • MiniCPM: runtime/minicpm_server.py.
  • 추가 음성 모델·코덱: runtime/speech_worker.py, runtime/speech_manager.py.
  • Polly·Sonic 실제 호출: server.mjs, sonic.mjs. 카탈로그 설명이 호출 코드와 다르면 실행 경로는 이 코드로 확인합니다.
