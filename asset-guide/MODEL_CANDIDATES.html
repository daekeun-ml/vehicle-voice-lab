추가 모델 후보: Qwen3-ASR, Kokoro, MiniCPM 최신 계열

현재 연결 모델 · 에셋 안내 · 확인한 리비전·메타데이터

확인일: 2026-10-22. 공식 모델 카드와 Hugging Face 메타데이터를 확인한 후보 검토입니다. 이후 Kokoro는 가중치를 내려받아 한국어 음소 입력 실행·재인식 진단을 수행했습니다. 추가로 Supertonic 3·Qwen3-TTS 1.7B·CosyVoice 3의 한국어 8문장 비교를 완료했습니다. Qwen 1.7B·Supertonic 3는 서울 공유 데모에 연동하고 모델별 요청을 검증했습니다. Qwen3-ASR 0.6B·1.7B도 GPU2에 연동했으며 STT 4종 비교를 실행합니다. 나머지 후보 상태는 아래에 구분했습니다. 현재 기본 모델과 기존 평가 점수는 유지합니다.

우선 검토할 STT: Qwen3-ASR 두 크기

후보 공식 한국어 지원 라이선스 이 앱에서 맡을 역할
Qwen/Qwen3-ASR-0.6B 명시됨 Apache-2.0 Whisper/Nemotron 대신 음성 → 텍스트
Qwen/Qwen3-ASR-1.7B 명시됨 Apache-2.0 같은 입력으로 0.6B와 정확도·시간·메모리 비교

두 모델은 음성 인식 모델입니다. 차량 명령 JSON을 만드는 Qwen/Qwen3.5-4B와 역할이 다릅니다. 도입 시 비교 경로는 다음과 같습니다.

음성 → 선택한 Qwen3-ASR → 인식 텍스트 → 기존 Qwen3.5-4B NF4 → 차량 실행기 → 기존 TTS

공식 카드는 한국어를 포함한 30개 언어와 중국어 22개 방언을 명시합니다. qwen-asr 패키지가 Transformers·vLLM 실행을 지원하고, 카드의 스트리밍 경로는 vLLM을 사용합니다. 처음에는 기존 앱과 같은 발화 단위로 비교하고, 스트리밍 통합은 별도로 평가하는 편이 조건을 통제하기 쉽습니다. 제품의 스트리밍 지원이 곧 이 앱의 스트리밍 연동을 뜻하지는 않습니다.

0.6B·1.7B는 제품 크기 표기입니다. 확인한 Hub safetensors 메타데이터의 전체 텐서 파라미터 수는 각각 938,008,576과 2,349,217,408입니다. 메모리는 이름의 숫자만으로 산정하지 않고 인코더 등을 포함한 로딩·요청 peak를 직접 측정해야 합니다.

비교 시 다음 조건을 고정합니다.

  • 동일 음성, 동일 한국어 전사 정답, 동일 텍스트 정규화 규칙.
  • 뒤쪽 판단 모델·프롬프트·차량 가드·TTS는 그대로 유지.
  • 한국어 CER, 숫자·좌석·부정·정정 인식 정확도와 최종 차량 제어 성공률을 분리.
  • warm/cold 시간, 전사 완료 시간, GPU peak 메모리 측정. vLLM의 기본 메모리 예약량을 GPU 1의 다른 상주 워커와 함께 검토.
  • 고난도 48문제는 현재 텍스트 명세이므로 STT 시험 전에 사람 녹음이나 합성 음성을 별도로 준비.

두 후보를 기존 워커에 무조건 추가 상주시키는 배치는 전제하지 않습니다. 같은 GPU의 메모리 예산을 확인하며 ASR 후보를 하나씩 로드해 비교할 수 있습니다. forced aligner는 선택적 타임스탬프 기능이며 이번 차량 명령 전사 비교에 필수로 추가하지 않습니다.

TTS 후보: Kokoro-82M

hexgrad/Kokoro-82M은 82M 파라미터의 공개 가중치 TTS 모델이며 Apache-2.0 라이선스로 안내됩니다. 공식 예제는 kokoro.KPipeline, misaki 계열 발음 처리와 espeak-ng를 사용하고 24kHz 오디오를 생성합니다.

공식 VOICES.md에 한국어 voice/lang_code는 없습니다. 영어·일본어·중국어·스페인어·프랑스어·힌디어·이탈리아어·포르투갈어 등의 음성이 있으므로, 현재는 영어 TTS의 경량 실행 후보로 둡니다. 이 저장소의 Polly Seoyeon·Qwen 한국어 TTS를 바로 대체할 수 있다고 표시하지 않습니다.

검토할 항목은 다음과 같습니다.

  • 같은 영어 안내 문장을 읽게 했을 때의 자연스러움, 숫자·지명 발음, 짧은 응답의 명료성.
  • CPU와 GPU에서 각각 측정한 첫 오디오 시간·전체 생성 시간·메모리. 82M이라는 크기만으로 차량 CPU의 지연을 단정하지 않음.
  • 24kHz 출력과 현재 앱의 오디오 재생·WAV 처리 연결.
  • 공식 음성 문서가 지적하는 짧은 발화의 약점. 차량 안내는 짧으므로 긴 문단 합성 점수로 대신 평가하지 않음.

한국어 확장·파인튜닝·커뮤니티 포크는 원본 hexgrad/Kokoro-82M의 공식 지원과 구분해야 합니다.

추가 실행 결과: ko·k 모드는 거부됐지만 한국어 음소를 직접 넣는 방법으로 16개 오디오를 생성했습니다. 인사말 일부를 제외하면 차량 안내의 재인식 오류가 커서 한국어 기본 TTS에 연결하지 않았습니다. 이 결과는 사람이 청취해 판정한 품질 점수가 아닙니다. 실행 방법·한계와 생성 음성을 참고하세요.

Kokoro 대안 TTS 3종: 실행 비교 완료

모델 실행 구성 재인식 완전 일치
Supertone/supertonic-3 CPU · F1 · 한국어 6/8
Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice GPU · Sohee · BF16 7/8
FunAudioLLM/Fun-CosyVoice3-0.5B-2512 GPU · 합성 참조 음성 · fp16 옵션 5/8

24개 음성 청취와 설정·실패 사례·측정 한계를 확인하세요. 동일 8문장의 ASR 대리 지표이며 MOS가 아닙니다. CosyVoice는 0.08초로 끝난 짧은 인사말 실패를 포함합니다. 기존 0.6B·Polly를 이번에 재측정하지 않았으므로 기존 기본값 대비 우위를 주장하지 않습니다.

MiniCPM-o-4.5보다 최신 모델은?

확인한 공식 MiniCPM-o-4.5 카드는 4.5를 MiniCPM-o 계열의 최신 모델로 설명합니다. 확인한 OpenBMB 공식 공개 목록에서 더 새로운 o 계열 기본 모델은 찾지 못했습니다.

새로운 버전 숫자가 붙은 다른 계열은 있지만, 입력·출력 기능이 다릅니다.

모델 Hub 저장소 생성 시점¹ 역할 이 앱에서의 판단
MiniCPM-o-4.5 2026-02-03 영상·음성 이해, 음성 생성, 전이중 대화 기존 음성 모델 비교 기준 유지
MiniCPM-V-4.7-1B 2026-10-06 이미지·영상 → 텍스트 음성 모델의 직접 후속 교체 대상이 아님
MiniCPM5-2B 2026-09-06 텍스트 생성 STT 뒤의 판단 모델 후보로 별도 검토 가능

¹ 저장소 생성일은 모델 발표일·학습 완료일과 다릅니다. 최근 파일 수정일이나 양자화 포맷 추가일도 새 세대 출시일로 취급하지 않습니다.

MiniCPM-o-4.5의 공식 음성 대화 지원은 영어·중국어로 안내됩니다. 카드의 30개 이상 언어 지원 설명을 한국어 음성 입출력 보장으로 확장해서 읽으면 안 됩니다. 한국어 차량 명령 적합성은 기존 점수와 고난도 신규 평가로 확인해야 합니다.

앱은 503e754207c94da6bb26850b4469f367c9ea3582 리비전을 고정하고 있습니다. 이번에 확인한 저장소 head는 d59117d19ddb8a28a62f1b5f4e3b34ac48d510a4로 다릅니다. head가 다르다는 사실만으로 가중치나 모델 세대가 바뀌었다고 단정할 수 없습니다. 업데이트하려면 변경 파일과 기존 음성 어댑터 호환성을 먼저 비교해야 합니다.

Step-Audio-R1.1은 기존 Step-Audio-2-mini보다 새로운 대안이지만 MiniCPM-o-4.5보다 저장소 생성일이 늦지는 않습니다. 공식 배포 안내는 4×L40S/H100/H800/H20에서 시험했다고 명시합니다. 확인된 약 33.49B BF16 파라미터는 가중치만 약 62.4GiB이므로 현재 단일 L40S 48GB에 같은 설정으로 바로 올릴 수 없습니다. 양자화·분산·offload 가능성을 실제로 확인하지 않고 “현재 GPU에서 실행 가능”으로 표시하지 않습니다.

MiMo-V2.5-ASR은 2026-04에 생성된 더 최근 ASR 저장소지만, 공식 설명의 중국어·영어 성능을 한국어에도 적용할 근거는 확인하지 못했습니다. MiniCPM-o의 음성 대화 역할 전체를 대체하는 모델도 아닙니다.

이번 결정

  1. 한국어 STT 비교 우선순위: Qwen3-ASR-0.6B와 1.7B를 모두 후보에 추가.
  2. TTS: Kokoro-82M은 영어·경량 실행 후보. 한국어 기본 TTS는 기존 구성 유지.
  3. 음성 직접 이해: MiniCPM-o-4.5의 최신성만을 이유로 제외하지 않음. 공식 후속 모델 확인과 한국어 실측을 구분.
  4. 최신 텍스트 모델: MiniCPM5-2B는 STT 뒤의 판단 모델 후보로 검토 가능.

후보와 근거는 별도 검토 JSON에 저장했습니다. 현재 실행 가능한 모델 카탈로그·선택기와 평가 결과에는 미연동 후보를 실행 완료 모델로 추가하지 않았습니다.
