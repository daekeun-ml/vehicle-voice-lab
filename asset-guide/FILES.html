화면·음성 에셋

위치 무엇인가요? 어떻게 보면 되나요?
한국어 화면 / 영어 화면 데모 화면을 찍은 이미지 앱의 전체 모습을 먼저 확인
sample-command.wav 한국어 차량 명령 입력 샘플 “조수석 온도 25도” 테스트에 사용
sample-english.wav 영어 입력 샘플 영어 음성 테스트에 사용
sample-greeting.wav MiniCPM 경로에서 쓰는 별도 입력 샘플 해당 모델의 샘플 음성 테스트에 사용
reference-neutral.wav MiniCPM 음성 생성에 사용하는 참조 음성 음성 생성 설정용 자료
benchmark-audio 폴더 모델 비교 실험에서 저장한 응답 음성 모델별 시험 응답을 직접 들어보기
favicon.svg 브라우저 탭의 작은 아이콘 앱 표시용 이미지

비교 음성 파일명은 모델명-시험내용-reply.wav 형태입니다.

  • passenger-25: 조수석 온도 25도 요청.
  • defrost-on: 앞유리 김서림 제거 켜기 요청.
  • reply: 사용자의 입력이 아니라 시스템의 응답 음성.

예를 들어 qwen35-4b-nf4-passenger-25-reply.wav는 Qwen3.5-4B NF4 설정으로 조수석 온도 요청을 시험했을 때의 응답입니다. 파일의 모델명이 곧 목소리를 만든 모델이라는 뜻은 아닙니다. 명령 판단은 해당 모델이 하고, 음성은 Polly 같은 별도 서비스가 만들 수 있습니다.

목적에 따라 이 파일부터 보세요

  • “무슨 앱인지 알고 싶다” → 쉬운 설명, 한국어 원본 안내.
  • “비교 결과가 궁금하다” → 비교 CSV, 평가 요약 JSON. CSV는 표 형태, JSON은 프로그램이 읽기 좋은 데이터 형태입니다.
  • “어떤 문장으로 시험했나?” → 평가 문장과 정답 정의.
  • “더 어려운 문제는?” → 별도 고난도 48문제와 해설, 평가 입력·정답 JSON. 신규 세트이며 모델 평가·음성 생성은 아직 미실행.
  • “정확히 어떤 모델을 쓰나?” → 서버별 모델 ID·크기·정밀도.
  • “새 STT·TTS와 최신 모델 후보는?” → Qwen3-ASR·Kokoro·MiniCPM 최신 계열 검토, 후보 메타데이터.
  • “잡음 제거와 Kokoro를 직접 시험한 결과는?” → 잡음 제거 설계·실험, Kokoro 한국어 진단, 오디오 A/B 청취 페이지.
  • “다른 한국어 TTS 3종 비교는?” → Supertonic·Qwen 1.7B·CosyVoice 실행 결과, 24개 생성 음성 듣기.
  • “코드가 어떻게 연결되나?” → 한국어 아키텍처 설명, AWS 아키텍처 그림, 기존 영문 상세 구조.
  • “직접 실행하고 싶다” → 배포 안내.
  • “가져다 써도 되나?” → 앱 라이선스, 모델별 주의사항.
