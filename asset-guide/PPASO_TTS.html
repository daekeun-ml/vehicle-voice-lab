Ppaso-TTS 한국어 경량 음성 합성

Kokoro를 UI·API·실행 서비스에서 제거하고 akamotaco/ppaso-tts-v1로 교체했습니다. TTS 비교 화면에서 Ppaso-TTS · 한국어 · ONNX CPU를 선택하세요.

한국어 텍스트를 mecab-ko와 발음 사전으로 음소화한 뒤 text encoder → variance → acoustic → vocoder → CPU iSTFT 순서로 합성합니다. 음성 복제나 여러 화자 선택은 지원하지 않습니다. 제작자가 자연스러움보다 속도·크기를 우선했다고 명시하므로 기계적인 음색이 남을 수 있습니다.

직접 시험

  1. 새 모델 테스트에서 Ppaso 카드의 이 모델로 생성을 누릅니다.
  2. 재생·음성 다운로드로 발음을 확인합니다.
  3. 온도, 부정 표현, 소수·좌석, 목적지 예제를 각각 시험합니다.
  4. 차량 대화에 사용을 누르면 이후 차량 응답에 Ppaso를 사용합니다.

비교 카드의 단독 합성은 차량 상태를 변경하지 않습니다. 기본 응답 음성은 Polly를 유지합니다. Kokoro를 요청하면 다른 모델로 대체하지 않고 잘못된 선택으로 거부합니다.

속도와 품질 해석

모델 카드의 305ms / RTF 0.052는 RK3576 NPU 측정값이며 이 EC2 결과가 아닙니다. 여기서는 ONNX CPU로 별도 측정합니다. 모델의 문장 단위 스트리밍 기능과 현재 앱 통합도 구분해야 합니다. 현재 앱은 입력 문장의 합성이 끝난 뒤 WAV를 반환합니다.

8개 고정 한국어 문장으로 실제 합성하고, 기존 Whisper large-v3-turbo에 재입력해 숫자·좌석·부정 표현을 진단합니다. 재인식 결과는 발음 오류 탐지의 보조 지표이며 사람이 평가한 자연스러움이나 MOS가 아닙니다.

설치·재현

코어 호스트 /opt/vehicle-voice에 runtime/tts_worker.py, runtime/ppaso_text.py, runtime/bootstrap_ppaso.sh를 배치하고 다음을 실행합니다.

bash /opt/vehicle-voice/bootstrap_ppaso.sh

별도 Python 3.12 ppaso-env에 onnxruntime, python-mecab-ko, numpy, soundfile 등을 설치합니다. 모델 revision은 워커에서 고정합니다. Hugging Face 캐시의 심볼릭 링크가 ONNX 외부 가중치 경로 검사에 걸리지 않도록, 해당 snapshot을 실제 파일 디렉터리로 복사한 후 로드합니다. 경로 검사는 비활성화하지 않습니다.

웹 서버 환경 변수는 PPASO_TTS_URL=http://127.0.0.1:9108입니다. 개발용 SSH 터널은 로컬 19108을 사용합니다.

python3 scripts/probe-ppaso-live.py

위 스크립트는 8문장 합성·Whisper 재인식·모델 ID/revision·차량 상태 무변경·Kokoro 선택 거부를 검증하고 research/tts-comparison/ppaso.json에 저장합니다.

이번 배포 실측

8개 고정 문장의 합성 중앙값은 64.0ms입니다. 초기 호출을 포함한 범위는 63~183ms입니다. 네트워크 왕복과 브라우저 재생 대기는 포함하지 않습니다.

Whisper 재인식의 정규화 문장 일치는 6/8입니다. 소수점 누락을 확인해 소수·음수 전처리를 보완한 개발 세트 결과이며, 수정 전 원음과 결과는 ppaso-before-text-fix.json에 보존합니다. 현재 남은 불일치는 목적지 → 목적치, 바람 세기 → 바람 새기입니다. 모델 발음과 재인식 모델 오류를 분리한 사람 청취 평가는 아직 하지 않았습니다.
