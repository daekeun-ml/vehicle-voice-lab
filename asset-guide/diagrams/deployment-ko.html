AWS 배포 구성: 화면부터 모델까지

서울 공유 배포 구성입니다. 실시간 상태는 앱의 health API에서 확인합니다. GPU 1은 Core·Whisper·Qwen TTS 0.6B/1.7B·MiniCPM 워커가 같은 GPU의 VRAM을 공유합니다. Core는 판단 모델 1개와 필요할 때 로드하는 Nemotron ASR을 사용합니다. GPU 2는 Qwen3-ASR 두 모델을 독립 실행하며, 추가 음성 모델만 하나씩 교체합니다. 각 워커의 상주 여부와 한 요청의 모델 호출 경로는 별개입니다. Supertonic 3와 Ppaso는 GPU 1 호스트의 CPU에서 실행합니다. Ppaso는 한국어 전용 ONNX 경로입니다. AgentCore Gateway는 선택 확장이며 이번 배포에는 구성하지 않았습니다. 로컬 정보 도구는 별도 어댑터를 사용합니다.
